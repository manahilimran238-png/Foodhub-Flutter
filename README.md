# 🍔 FoodHub Flutter

![Flutter](https://img.shields.io/badge/Flutter-3.x-blue?logo=flutter)
![Dart](https://img.shields.io/badge/Dart-3.x-blue?logo=dart)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Completed-success)

FoodHub Flutter is a modern food ordering mobile application developed using Flutter. It provides a clean and intuitive user interface where users can browse food items, search meals, manage favorites, and explore different sections of the application.

---

# ✨ Features

- 🍔 Browse delicious food items
- 🍕 Organized menu categories
- 🔍 Search functionality
- ❤️ Favorite food items
- 📦 Order history
- 👤 User profile
- ⚙️ Settings page
- 📞 Contact page
- ℹ️ About page
- 🎨 Responsive Material Design interface

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/manahilimran238-png/Foodhub-Flutter.git
```

Move to the project directory

```bash
cd Foodhub-Flutter
```

Install packages

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
